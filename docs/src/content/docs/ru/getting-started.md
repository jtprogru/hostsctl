К концу страницы у тебя будет конфиг, одна запись в нём и эта запись в `/etc/hosts` —
причём всё, что уже было в файле, останется на месте.

## Что нужно

- Linux или macOS. hostsctl построен вокруг `/etc/hosts`, `libc` и системного сброса
  DNS-кеша, поэтому сборки под Windows нет.
- `sudo` для команд, которые пишут в `/etc/hosts`. Всё остальное работает от обычного
  пользователя.

## 1. Установка

```bash
brew install jtprogru/tap/hostsctl
```

Остальные способы — crates.io, скрипт установки, архив релиза — на странице
[Установка](/hostsctl/ru/install/).

## 2. Создать конфиг

```bash
hostsctl init
```

Создаётся `~/.config/hostsctl/config.yaml`. Больше пока ничего не происходит: `init` не
трогает `/etc/hosts`.

```bash
hostsctl config-path        # где конфиг лежит на самом деле
```

## 3. Добавить запись

```bash
hostsctl add 127.0.0.1 k8s.orb.local --comment orbstack
```

Запись попадает в группу `local`, которая создаётся при первом использовании. Сейчас она в
конфиге, но ещё не в `/etc/hosts`.

```bash
hostsctl list
```

## 4. Посмотреть до записи

```bash
hostsctl diff
```

`diff` собирает то, что дал бы `apply`, и показывает unified diff относительно текущего
файла. Он ничего не пишет и не требует root — поэтому это первая команда, когда неясно,
что изменение сделает.

```bash
hostsctl check
```

`check` — линтер: показывает то, что `/etc/hosts` молча проигнорирует. Wildcard, порт в
имени хоста, адрес, который не адрес.

## 5. Применить

```bash
sudo hostsctl apply
```

hostsctl показывает diff, спрашивает подтверждение (`-y` пропускает вопрос), снимает
бэкап текущего файла, пишет атомарно и сбрасывает DNS-кеш.

```bash
hostsctl status
```

`status` показывает конфиг, состояние управляемого блока, все группы и бэкапы. Если файл
разъехался с конфигом — скажет об этом и на сколько строк.

## Как откатить

Три уровня, от мягкого к жёсткому:

```bash
hostsctl disable k8s.orb.local && sudo hostsctl apply   # оставить, но не использовать
sudo hostsctl off                                       # убрать весь блок
sudo hostsctl backup restore                            # откатить файл
```

`off` не трогает конфиг — он только убирает управляемый блок из `/etc/hosts`, поэтому
следующий `apply` вернёт всё обратно.
